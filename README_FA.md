# CNFinder

ابزار **CNFinder** یک ابزار سبک برای استخراج و شناسایی رکوردها (Enumeration) CNAME است که برای متخصصان تست نفوذ وب و محققان امنیت ساخته شده است.

> این ابزار دستورات تکراری جستجوی DNS را خودکار می‌کند و به شما اجازه می‌دهد تا به سرعت لیستی از دامنه‌ها را بررسی کرده و رکوردهای CNAME آن‌ها را بدون نیاز به اجرای دستی دستورات `dig` یا `nslookup` برای تک‌تک هدف‌ها شناسایی کنید.

> این اسکریپت نیازی به نصب هیچ پیش‌نیازی ندارد؛ فقط کافیست فایل cnfinder.py را اجرا کنید تا نتیجه را بگیرید.


## نحوه استفاده

### ورودی

یک فایل `.txt` حاوی دامنه‌ها را مشخص کنید:

```bash
python cnfinder.py -i domains.txt
```

### خروجی

ذخیره دامنه‌هایی که رکورد CNAME پیدا شده در یک فایل `.txt`:

```bash
python cnfinder.py -i domains.txt -o results.txt
```

## فلگ‌ها (Flags)

| فلگ | توضیحات |
| ---------------- | ------------------------------------------ |
| `-i`, `--input` | فایل متنی `.txt` ورودی حاوی دامنه‌ها |
| `-o`, `--output` | فایل متنی `.txt` خروجی برای رکوردهای CNAME پیدا شده |

## قابلیت‌ها (Features)

* استخراج و شمارش رکوردهای CNAME
* خودکارسازی جستجوهای تکراری DNS
* پشتیبانی از ورودی و خروجی متنی (.txt)
* پشتیبانی از ویندوز، لینوکس و مک
* بدون نیاز به وابستگی‌ها و کتابخانه‌های جانبی پایتون
